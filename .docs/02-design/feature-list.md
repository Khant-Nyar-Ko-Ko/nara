# NaraNews — Feature List (DISCOVER Design)

Source: [backlog.md](../01-requirements/backlog.md), [20260902-01-news-digest.md](../01-requirements/01-spec/20260902-01-news-digest.md). ★ = core feature (built first). Scope: month-2 build only.

1. ★ **One-line headline digest** — headlines from several Thai news sites in one feed (kills P2, the best-supported pain: 7/7 rate scattered sources ≥3/5), each summarized to one line in a clickable popup list that opens the source article. (Traces to: F1, F2 — Must; P2, P3)
2. **Email digest when away** — the same digest sent by email when the reader is not active in Chrome. (Traces to: F3 — Must; P1)
3. **Sign-in & consent for email** — verified email login, recorded ToS/Privacy consent, purpose-limited email use, ≥90-day access logs; required by law before feature 2 can ship. (Traces to: LR1–LR4 — Mandatory; F3)

Cut from month-2 build: F5 Chrome notification (Should) and LR5 (only needed for F5); F4 breaking-news follow-up (Won't).
