## 3. Competitor analysis

Checked 2026-10-01. Source column says how each cell was verified.

| Competitor | Type | Thai sources in one place | Short / AI summary | Inside Chrome (toolbar popup) | Email digest when away | Source |
|------------|------|---------------------------|--------------------|-------------------------------|------------------------|--------|
| Google News | App + web | Yes | **Yes — AI summaries** (B6a) | No — website only; no official extension found | No (Google Alerts is a separate product) | B6a; web search |
| ข่าวประเทศไทย / Thailand News | Android app | Yes — Thairath, Khaosod, Daily News, PPTV, Ch 3/7/9… | No mention in store listing | No | No — push notifications by category | Play store description |
| LINE TODAY | Tab inside LINE | Yes | No — full articles; "doesn't pick out the important news" (B3b) | No | No | B3b |
| norsorpor.com | Website | Yes — near every Thai newspaper (B2) | No — headline list | No — must visit | No | B2 |
| Inoreader | RSS reader + Chrome extension | Only if you add Thai feeds yourself | AI summaries in email digests | Yes | **Yes, but Team/Custom plans only** | [Inoreader blog, 2025-08](https://www.inoreader.com/blog/2025/08/redesigned-email-digests-for-more-control-and-flexibility.html) |
| Feedly | RSS reader | Only if you add Thai feeds yourself | **Yes — Pro+/Business plans** | Web app | Automated newsletters (business plans) | [Feedly AI](https://feedly.com/new-features/posts/feedly-ai-and-summarization) |
| "จบข่าว" Facebook page | Social page | Editor-picked | Yes — 2–3 sentences (B5) | No | No | B5 |

**Takeaway:** every piece of NaraNews exists somewhere — aggregation (Google News, Thailand News, norsorpor), AI summaries (Google News, Feedly), email digests (Inoreader). What we did not find is **all of it together, free, set up for Thai sources out of the box: Thai outlets + one-line summary + Chrome toolbar popup + email digest when away**. The closest (Inoreader/Feedly) need manual Thai feed setup and paid plans for summaries/digests. Be ready for the gate question "why not just use Google News?" — answer: no Chrome popup, no email digest, and its summaries are inside an app you have to open (P1).
